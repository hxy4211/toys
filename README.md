## 小面宝宝桌宠

<img src="preview-states.png" width="820">

双击 `pet/启动小面.vbs` 启动。操作：

- **移动鼠标** → 它会朝你的方向偏头
- **按住拖动** → 拖到任意位置，松手有果冻回弹，位置记住
- **单击** → 蹦一下 + 冒台词
- **双击** → 睡觉 / 叫醒（Zzz）
- **右键** → 菜单（说句话 / 睡觉 / 回右下角 / 隐身 10 分钟 / 退出）

只在 `DSH Desktop` 运行时出现，关掉 DSH 它自动隐藏。

技术细节、抠图流程、换照片的方法都写在 [`pet/README.md`](pet/README.md) 里。
