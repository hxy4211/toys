用来玩 AI 工具的小玩具集合。一个仓库装多个小项目，每个玩具自成一体。

## 玩具列表

| 玩具 | 版本 | 说明 |
|---|---|---|

## 小面宝宝桌宠

<img src="preview-states.png" width="820">

**首次使用**：双击 `pet/install_autostart.bat` 一次（装开机自启 + 立即启动）。之后每次开机自动运行；手动启动可双击 `pet/start_pet.vbs`。

- **移动鼠标** → 它会朝你的方向偏头
- **按住拖动** → 拖到任意位置，松手有果冻回弹，位置记住
- **单击** → 蹦一下 + 冒台词
- **双击** → 睡觉 / 叫醒（Zzz）
- **右键** → 菜单（说句话 / 睡觉 / 回右下角 / 隐身 10 分钟 / 退出）

只在 `DSH Desktop` 运行时出现；**关掉 DSH，桌宠就彻底退出**，不在后台留驻。下次打开 DSH 会自动回来。高度可在 `pet/config.json` 里改。

## 目录约定

```
toys/
├── README.md          ← 就是本文件：玩具索引 + 仓库约定
├── <玩具名>/          ← 每个玩具一个目录，自成一体
│   ├── README.md      ← 这个玩具的说明、操作方式、技术细节
│   ├── .gitignore     ← 排除该玩具的依赖/运行时产物
│   └── ...            ← 代码、素材、工具脚本
└── <共用素材>          ← 真正跨玩具共用的图/脚本才放根目录
```

## 新增一个玩具

1. 在根目录建 `玩具名/`，写自己的 `README.md` 和 `.gitignore`
2. 在本文件「玩具列表」表格里加一行
3. 提交后打标签 `玩具名-v1.0`

```bash
git add -A && git commit -m "feat(<玩具名>): 首个版本"
git tag -a <玩具名>-v1.0 -m "<玩具名> v1.0" && git push --tags
```

## 版本与标签约定

**标签带项目前缀**：`pet-v1.0`、`snake-v1.0`……不用裸 `v1.0`，否则玩具一多就分不清哪个是哪个的发版。

**日常推送**：

```bash
git add -A && git commit -m "<玩具名>: 说明"
git push                                    # 推分支
git tag -a <玩具名>-v1.1 -m "..." && git push --tags   # 推版本
```

## 仓库卫生

- 依赖、虚拟环境、构建产物一律 **gitignore**（`.pylibs/`、`node_modules/`、`dist/`、运行时状态文件）
- 大二进制（视频、模型、图片素材包）尽量别直接提交，必要时用 Git LFS —— Git 历史一旦写进大文件就很难清
- 现在的 `.gitignore` 写法是"每个玩具管好自己"，新玩具照抄一份即可

## 更新记录

**pet-v1.2** — 自启更可靠，进程互为兜底

- 开机自启改用 HKCU Run 注册表键（启动文件夹快捷方式作为兜底），不再依赖会被清掉的文件夹
- 守护进程和桌宠互为兜底：任何一个挂了，另一个会把它拉回来
- 一次性确认 DSH 是否存在的判定，避免枚举失败造成闪退

**pet-v1.1** — 和 DSH 同生共死

- 新增守护进程 `watchdog.py`：打开 DSH 自动出现，关闭 DSH 桌宠彻底退出（不留后台驻留）
- 单实例保护，不会同时出现两个小面
- 一键安装开机自启：双击 `pet/install_autostart.bat`
- 脚本改为纯 ASCII 命名，规避 PowerShell / wscript 读中文的编码坑
- 清掉未使用的素材尺寸，抠图中间产物改为按需自动重建

**pet-v1.0** — 首个版本

- 从一张正面照抠出立绘（纯 Pillow，无 AI 模型，颜色 + 纹理双判据）
- Win32 分层窗口逐像素透明，空区域鼠标穿透
- 动作：跟手偏头、拖拽果冻回弹、双击睡觉（Zzz）、单击台词气泡
- 仅在 DSH Desktop 运行时出现，位置记忆，高度可配（`pet/config.json`）
